# Archived changes

Each folder is one OpenSpec change (proposal, delta specs, design, tasks). Its name starts with the date the change was
**archived**, so the folders sort by archive date and not by the order the system was built in: slice 1
(`2026-10-08-accounts-and-skeleton`) was archived after slice 2 (`2026-10-06-add-journal-entries`).

In the order they were built:

1. `accounts-and-skeleton`
2. `add-journal-entries`
3. `append-only-ledger-and-entry-guards`
4. `idempotent-replay`
5. `harden-request-validation`
6. `entry-reversal`
7. `immutable-accounts-and-as-of-balance`
8. `close-final-review-gaps`
9. `pin-trigger-search-path`
10. `add-ci-health-and-container-image`

The design of each, with the reasoning behind the code and the schema, is linked from
[docs/architecture.md](../../../docs/architecture.md).
